Known Issues

like USS Oklahoma City currently won't engage MiG-15 and F-86，cause both of them RCS were only 2.

and yes I'm aware USS Longbeach did Engage and shotdown 2 MiG-21 use RIM-8 at near 100km away. but DCS MiG-21 had RCS set to 3.
The AI's RCS value does not affect the detection status by distance. this results in a complete lack of flexibility in the settings. (only yes or no)
I don't want to reduce detection range or weapon range because for the small aircraft detection issue. 
Ultimately, the task of targeting aircraft with an RCS value of 2 or lower had to be transferred to other ships equipped with shorter-range missiles.
